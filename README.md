# Natural Language Processing (NLP) Experiment

## AIM
To study Natural Language Processing (NLP) techniques such as tokenization, stopword removal, stemming, lemmatization, POS tagging, and word frequency analysis using Python.

---

## THEORY

### 1. nltk.download()
Downloads required NLP datasets like tokenizers, stopwords, and lexical resources.

### 2. word_tokenize()
Splits text into individual words (tokens).

### 3. sent_tokenize()
Splits text into sentences.

### 4. stopwords.words()
Provides a list of common words (like “is”, “the”) to remove from text.

### 5. set()
Converts list into a set for faster lookup during filtering.

### 6. List Comprehension
Used to filter words by removing stopwords efficiently.

### 7. PorterStemmer()
Reduces words to their root form by removing suffixes.

### 8. stem()
Returns the stemmed (root) version of a word.

### 9. WordNetLemmatizer()
Converts words into their meaningful base (dictionary) form.

### 10. lemmatize()
Returns the correct base form of a word using vocabulary knowledge.

### 11. pos_tag()
Assigns grammatical tags (noun, verb, adjective, etc.) to each word.

### 12. FreqDist()
Calculates frequency distribution of words in a text.

### 13. most_common()
Returns most frequent words along with their counts.

### 14. POS Tagging
Identifies grammatical roles like noun (NN), verb (VB), adjective (JJ), etc.

### 15. Text Preprocessing
Includes tokenization, stopword removal, stemming, and lemmatization for cleaning text.

---

## CONCLUSION

In this experiment, various NLP techniques were applied to process and analyze text data. We learned how to tokenize text, remove stopwords, and reduce words using stemming and lemmatization. POS tagging helped identify grammatical roles, and frequency distribution helped analyze word usage. These techniques are essential for text analysis and natural language understanding.
